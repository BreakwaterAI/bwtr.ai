Connect from inside.

Collectors initiate tenant-authenticated connections. Mutual TLS authenticates both ends of the channel carrying telemetry, evidence and approved response.

Local evidence

Keep raw data close.

Signed metadata and claims cross first. Raw packets and sensitive payloads stay local by default; retrieval has a separate owner-approved scope.

Retrieval by approval
Scoped execution

Return action to its owner.

The response design uses an allowlisted, least-privilege local relay. An approved action returns to the original control, followed by a check of the final state.

Local execution + verification
Inside an action envelope

A proposed change needs more than a command.

The reference design carries the target, authority and recovery information together. That gives the local relay a defined instruction to execute and verify.
