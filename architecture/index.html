Before installation

Resolve the deployment questions.

Put the answers in the evaluation scope so the technical team and system owner work from the same assumptions.

  • Collection and accessWhich sources are available? Who permits access, and which collection methods can the systems tolerate?
  • Data handlingWhich records may leave a source system? Agree location, retention, access and deletion requirements, including restrictions on sensitive data.
  • Analysis placementIdentify hosting, connectivity and isolation requirements. Confirm the supported configuration against those requirements before choosing an installation pattern.
  • Assessment and changeName the person who authorizes each action, the allowed operating window, and the evidence needed to check the result.
